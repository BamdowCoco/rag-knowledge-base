About · architecture · boundaries

一条可本地复现的 RAG 入库与问答链路

从真实上游抓取文档，经标准化、分块与向量化写入 Qdrant，再用检索到的片段生成带引用的流式回答。 前端刻意保持零构建，把复杂度留在后端与 AI 链路。

Overview

是什么

这是一个企业知识库入库与问答的完整实现：同步器或爬虫提交原始文档，服务端按 source + external_id 判重与更新，分块后由独立 embedder 写入向量库；问答侧先检索、再回表取正文，最后把上下文交给模型流式生成。

演示页只做展示，不在浏览器里实现 RAG 逻辑。聊天页与静态资源由 rag-api 同源提供；运维页读取 api 的只读统计接口。

Architecture

角色分离的三条链路

api 只负责摄入与统计， rag-api 只负责检索与问答。这样读侧不持有写权限，部署时也更接近生产上的读写分离。

Stack

技术栈

API
FastAPI · Pydantic · SQLAlchemy async · Alembic
存储
MySQL 8（文档与分块）· Redis 7（队列状态、缓存、爬虫计数）· Qdrant（向量）
向量化
fastembed + BAAI/bge-small-zh-v1.5，独立 embedder 服务消费 pending chunk
生成
OpenAI 兼容接口（本机 Ollama qwen2.5:3b-instruct）；失败降级 extractive
爬虫
sitemap 增量、ETag / Last-Modified 校验、删除信号；遵守 robots 与限速
检索
dense 默认；hybrid 可选、默认关闭（当前评测未见稳定召回提升）
前端
原生 ES modules + CSS 变量，零构建、无 CDN、无外部字体
评测
recall@k、MRR、nDCG、引用精确率/召回率、拒答指标与延迟分位数
部署
Docker Compose；api / rag-api 角色分离，静态页由 rag-api 同源挂载

Boundaries

诚实边界

  • 模型质量有限。 公网演示接入 DeepSeek（OpenAI 兼容接口），回答质量取决于模型；调用失败时降级为原文片段拼接， 仍可演示链路，但不是完整生成。done.degraded 会明确标记。
  • 单轮问答。 服务端不保存多轮上下文，session_id 仅回显给前端做会话关联。
  • 引用不等于逐句支撑。 后端会校验越界引用编号，但无法保证每句话都被引用支撑；引用只代表本次检索到的资料。
  • 访问控制是共享账号。 公网用 Caddy Basic Auth + 路径白名单只开放问答页和关于页；访客账号访问运维页或摄入接口会被拒绝。 Basic Auth 不区分用户身份，没有退出登录与细粒度权限；聊天接口也尚未限流。
  • 单机演示环境。 Azure 单机 + Caddy 自动 HTTPS；没有多副本、自动备份与监控告警。
  • 评测集规模有限。 指标用于回归对比，不代表生产语料上的绝对质量；hybrid 的收益仍需更大评测集验证。
  • Prompt injection 不能完全防住。 当前用分隔符与指令层级降低风险；内容审核、权限隔离与工具隔离超出本项目范围。
