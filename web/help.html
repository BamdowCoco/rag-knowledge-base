演示访问说明

这个页面不需要登录。演示系统分两个入口，账号由投递邮件或消息单独提供。

访客入口

问答页 https://bamdow.kdns.fr/demo/

访客账号只能访问问答页和关于页；来源固定为 FastAPI 中文文档，召回数固定为 5。

站主入口

控制台 https://bamdow.kdns.fr/

站主账号用于完整前端、运维页和文档摄入接口；站主账号不能登录访客区，访客账号也不能进入站主区。

输错密码为什么没有提示？

演示站点使用 HTTP Basic Auth。用户名或密码错误时，服务器只能返回 401 Unauthorized，登录框由浏览器接管，所以会反复弹出，而不会显示“密码错误”。

  • 请先核对邮件或消息里的用户名、密码，注意不要多复制空格；
  • 弹框反复出现时，先点“取消”，再重新打开上面的问答页链接；
  • 如果仍然无法登录，账号可能已被撤销，请联系投递人重新发放。

提示：浏览器会缓存 Basic Auth 凭据。换账号测试时建议使用无痕窗口，避免继续使用上一次的登录信息。
